# 🧮 Calculadora Básica con TDD

Una **calculadora básica desarrollada aplicando la metodología TDD (Test-Driven Development)** para garantizar la robustez, fiabilidad y alta cobertura de código en todas las operaciones aritméticas.

## 🚀 Características principales

* **Operaciones básicas:** Suma, resta, multiplicación y división.
* **Flujo TDD estricto:** Código diseñado a partir de pruebas unitarias automatizadas (ciclo Red-Green-Refactor).
* **Control de errores:** Gestión de casos extremos, como el manejo correcto de la división por cero.
* **Código limpio:** Arquitectura simple y modular que facilita la lectura y extensión del código.

   ```bash
   cd calculadora-tdd
   ```

3. Instala las dependencias necesarias (framework de pruebas incluido):


## 🧪 Ejecución de las Pruebas (Test Suite)

Para comprobar el correcto funcionamiento de la calculadora y validar el flujo TDD, ejecuta el comando de pruebas:

```bash

# Ejemplo si es Python con pytest

```
